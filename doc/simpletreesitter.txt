1. INTRODUCTION                              *simpletreesitter-introduction*

simpletreesitter uses an asynchronous Rust daemon for Tree-sitter parsing,
highlight queries, symbol extraction and incremental syntax-tree updates.  Vim
renders namespaced text properties and an optional code Outline.  After the
first full snapshot, edits are shipped as line-range deltas (edit_lines), so
large buffers stay cheap to keep in sync.

Supported filetypes: rust, c, cpp, cc, javascript, javascriptreact, jsx,
typescript, typescriptreact, python, go, sh, bash, zsh, vim, vimrc, json,
jsonc, yaml, toml, lua, html, css and markdown.

Markdown uses two grammars: the block grammar drives structure (headings,
fences, lists, tables) and a second inline tree — parsed only inside the
block tree's inline ranges — adds emphasis, code spans and links.  The
Outline shows the heading hierarchy (h1..h6 map to distinct symbol kinds).

===============================================================================
2. REQUIREMENTS                              *simpletreesitter-requirements*

Vim 9.0+ with +vim9script, +job, +channel, +textprop and +timers; UTF-8; and
Rust 1.88+ when building the daemon.  Neovim is not supported.

Build or update the daemon from the plugin directory: >

  ./install.sh
<

3. COMMANDS                                  *simpletreesitter-commands*

                                                *:TsHlEnable*
:TsHlEnable             Enable highlighting and automatic synchronization.

                                                *:TsHlDisable*
:TsHlDisable            Disable, clear owned properties and stop the daemon.

                                                *:TsHlToggle*
:TsHlToggle             Toggle the plugin.

                                                *:TsHlOutlineOpen*
:TsHlOutlineOpen        Open or retarget the code Outline.

                                                *:TsHlOutlineClose*
:TsHlOutlineClose       Close the Outline.

                                                *:TsHlOutlineToggle*
:TsHlOutlineToggle      Toggle the Outline.

                                                *:TsHlOutlineRefresh*
:TsHlOutlineRefresh     Refresh symbols for the current Outline source.

                                                *:TsHlDumpAST*
:TsHlDumpAST            Show the AST for the current buffer revision.

                                                *:TsHlStatus*
:TsHlStatus             Show protocol, cache and parse statistics.  This
                        command does not start a stopped daemon.

                                                *:TsHlSymbols*
:TsHlSymbols            Collect the buffer's symbols into the location list
                        and open it.

                                                *:TsHlNextSymbol*
:TsHlNextSymbol         Jump to the next configured structural symbol and
                        wrap at the end.  A command count skips multiple
                        symbols.  The originating window/cursor/revision is
                        captured while the asynchronous request runs; moving
                        it cancels the stale jump and switching windows does
                        not steal focus.  Full results are cached per revision.

                                                *:TsHlPrevSymbol*
:TsHlPrevSymbol         Jump to the previous configured structural symbol and
                        wrap at the beginning.  A command count is supported.

                                                *:TsHlFoldsToggle*
:TsHlFoldsToggle        Toggle Tree-sitter folds.  When enabled the window
                        uses 'foldmethod' expr with fold levels computed from
                        the syntax tree; toggling off restores the previous
                        fold settings.

4. MAPPINGS                                  *simpletreesitter-mappings*

Default normal mappings are <Leader>th and <Leader>to.  Existing user mappings
are never replaced.  For custom mappings use: >

  nmap <Leader>x <Plug>(simpletreesitter-toggle)
  nmap <Leader>s <Plug>(simpletreesitter-outline-toggle)
  nmap ]s <Plug>(simpletreesitter-next-symbol)
  nmap [s <Plug>(simpletreesitter-prev-symbol)
<
Inside the Outline, <CR> jumps, o and za toggle a node, and q closes it.

5. OPTIONS                                   *simpletreesitter-options*

Set global options before loading the plugin.  Defaults are shown below.

g:simpletreesitter_auto_enable_filetypes     List of auto-start filetypes.
g:simpletreesitter_auto_stop                 1
g:simpletreesitter_daemon_path               ''
g:simpletreesitter_debounce                  120
g:simpletreesitter_scroll_debounce           300
g:simpletreesitter_max_buffer_bytes          5242880 (0 means unlimited)
g:simpletreesitter_clear_props_on_disable    1
g:simpletreesitter_incremental_sync          1 (line-delta sync, protocol v3)
g:simpletreesitter_folds                     0 (Tree-sitter folds)

g:simpletreesitter_view_margin               120
g:simpletreesitter_symbols_view_margin       10000
g:simpletreesitter_max_props                 20000
g:simpletreesitter_rainbow_brackets          1

g:simpletreesitter_outline_width             40
g:simpletreesitter_outline_fancy             1
g:simpletreesitter_outline_ascii             0
g:simpletreesitter_outline_hide_icon         0
g:simpletreesitter_outline_show_position     1
g:simpletreesitter_outline_disable_props     0
g:simpletreesitter_outline_max_items         1000
g:simpletreesitter_outline_scan_max_items    5000
g:simpletreesitter_outline_follow_cursor     1
g:simpletreesitter_outline_foldable          1
g:simpletreesitter_outline_spacing           1
g:simpletreesitter_outline_hide_inner_functions  1
g:simpletreesitter_outline_hide_fields       0
g:simpletreesitter_outline_hide_variants     0
g:simpletreesitter_outline_exclude_patterns  []
g:simpletreesitter_symbol_jump_kinds         function, method, class, struct,
                                             enum, namespace, type, module,
                                             macro ([] means all)

Navigation kind filtering is performed by a protocol-v4 daemon before its
bounded result limit. Markdown and structured-data filetypes intentionally
navigate all extracted levels. Rebuild the daemon after updating the plugin.

g:simpletreesitter_indent_guides             0
g:simpletreesitter_indent_guide_char         '│'
g:simpletreesitter_breadcrumb                0
g:simpletreesitter_breadcrumb_separator      ' > '

Use this expression in 'statusline' when Vim has no 'winbar': >

  %{simpletreesitter#Breadcrumb()}
<
Disable one buffer with: >

  let b:simpletreesitter_disable = 1
  let b:simpletreesitter_max_buffer_bytes = 0
<

6. TROUBLESHOOTING                          *simpletreesitter-troubleshooting*

"daemon not found"          Run ./install.sh or set the daemon path.
"protocol is outdated"      Rebuild the daemon after updating the plugin.
Large buffer is skipped      Raise max_buffer_bytes or set it to zero.
Icons look incorrect         Disable outline_fancy or enable outline_ascii.

Enable g:simpletreesitter_debug and inspect g:simpletreesitter_log_file for
daemon stderr and scheduling diagnostics.

DAEMON SUPERVISION                                   *simpletreesitter-daemon*

The Rust daemon is managed by simplecore, the supervisor shared by the whole
simple* plugin suite. It is vendored into this repository at
autoload/simpletreesitter/core.vim; that file is generated, do not edit it in place.

What it guarantees:

- Liveness is always read from |job_status()|. job_start() returns a job
  object even when the exec itself failed, so a daemon that cannot start is
  never mistaken for one that is running.
- A superseded daemon's late exit callback cannot clear the state of the
  replacement that already took its place.
- Output still queued when you stop the daemon is discarded, so an explicit
  stop cannot be undone by an event that was already in flight.
- A daemon that dies is restarted automatically with exponential backoff.
  If it keeps crashing, the supervisor reports it once and stops trying
  rather than respawning forever; :TsHlRestart re-arms it.
- Requests are correlated to replies by id and can time out, so a wedged
  daemon never leaves a callback hanging.

                                                      *:TsHlHealth*
:TsHlHealth
        Report daemon path, run state, negotiated protocol and capabilities,
        uptime, crash and restart counts, and whether the crash-loop breaker
        has tripped, alongside this plugin's own diagnostics.

                                                      *:TsHlRestart*
:TsHlRestart
        Stop the daemon and start a fresh one. Clears the crash-loop breaker,
        so this is the way back after repeated failures.

                                                      *:TsHlLog*
:TsHlLog
        Open the daemon transcript in a scratch buffer: start and exit events,
        restarts, protocol handshakes, send failures and stderr.


==============================================================================
DAEMON COMMAND LINE                              *simpletreesitter-daemon-cli*

The daemon takes no arguments in normal use: the plugin starts it and speaks
JSON over its stdin and stdout.  For diagnosis it also answers: >

  ts-hl-daemon --version
  ts-hl-daemon --help
  ts-hl-daemon --self-test
<
--self-test compiles every bundled grammar's queries and prints "ok".
install.sh runs it on the freshly built binary before replacing a working one,
so a build that compiles but does not work never reaches lib/.

Every daemon in the simple* suite answers these three the same way.

VENDORED SUPERVISOR                              *simpletreesitter-simplecore*

The daemon supervisor in autoload/simpletreesitter/core.vim, and the test
harness beside it, are vendored from the suite's shared .simplecore bundle
rather than written here — each plugin carries its own copy so that
installing this plugin alone is enough.  Do not edit those files in place: >

  make core-verify
<
checks each of them against the sha256 recorded in .simplecore.manifest and
fails the build when one has drifted.  `make check` depends on it.

The bundle lives at https://github.com/beamiter/simplecore.  To change the
supervisor, clone it beside the plugins, edit it there, and re-vendor: >

  git clone https://github.com/beamiter/simplecore ../.simplecore
  ../.simplecore/vendor.sh
<
